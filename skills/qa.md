# Skill: QA

Use to validate a feature, release, bug fix, or quality standard.

## Steps

1. Start from the delivery brief.
2. Convert acceptance criteria into test cases.
3. Identify automated checks.
4. Identify manual checks.
5. Run checks or record blockers.
6. Record `passed`, `failed`, `blocked`, `not_applicable`, or
   `risk_accepted`.
7. Create follow-up tasks for failures.

## Output

- Verification or QA artifact.
- Evidence references.
- Follow-up tasks.
