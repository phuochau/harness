# Skill: Task Planning

Use after a delivery brief exists.

## Steps

1. Read the delivery brief.
2. List required implementation, test, docs, review, verification, and trace
   work.
3. Split work into agent-sized tasks.
4. Assign each task to a role.
5. Add dependencies.
6. Mark `parallelizable: true` only when tasks have disjoint files or surfaces.
7. Ensure each task has proof required.

## Output

- Task files.
- Agent assignment plan.
- Parallel execution notes.
