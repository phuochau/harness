# Skill: Delivery Brief

Use for normal or high-risk work before implementation.

## Steps

1. Read the request.
2. Resolve blocking clarification markers.
3. Define outcome, scope, non-goals, current behavior, and target behavior.
4. Write acceptance criteria.
5. Write independent test scenarios.
6. Identify affected surfaces and risk.
7. Define required proof.
8. Write the delivery brief.

## Output

- Delivery brief artifact.
