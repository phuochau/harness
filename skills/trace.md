# Skill: Trace

Use at the end of work or when handing off.

## Steps

1. Summarize the run.
2. Link request, brief, tasks, review, and verification.
3. Record files read and changed.
4. Record proof collected and proof gaps.
5. Record remaining risk.
6. Record decisions.
7. Record workflow friction and follow-up work.

## Output

- Trace artifact.
- Decision artifact when needed.
