# Skill: Security Audit

Use for security audits or security-sensitive changes.

## Steps

1. Define scope.
2. Treat as high-risk unless explicitly narrowed.
3. Identify threat surfaces.
4. Collect evidence.
5. Record findings separately from fixes.
6. Rank severity and exploitability.
7. Create one fix task per meaningful finding.
8. Verify each fix with evidence.
9. Record decisions for security policy or architecture changes.

## Output

- Audit findings.
- Fix tasks.
- Verification notes.
- Decision records when needed.
