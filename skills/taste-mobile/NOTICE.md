## Accuracy and scope limits

- The score from the local direction-dealing script is a fit heuristic, not a
  statistical model, independent quality assessment or design-award prediction.
- Benchmark and reference research depend on the coding agent's live tools.
- Image concepts are not tested native screens. A native build and visual
  inspection are required to claim that a running app was inspected.
- The coding agent decides how to use tools already available. This skill has
  no bundled screenshot-taking or UI-automation dependency.
