# Skill: Principles

Use for greenfield projects or when a project needs explicit delivery
principles.

## Steps

1. Define non-negotiable standards for quality, testing, UX/API consistency,
   security, performance, and maintainability.
2. Keep principles short enough to be used as gates.
3. Mark which principles require human approval to change.
4. Add principle checks to review and planning.

## Output

- Project principles section or document.
- Principle gates for planning and review.
