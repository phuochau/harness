# Skill: Task Planning

Use after a delivery brief exists.

## Steps

1. Read the delivery brief.
2. List required implementation, test, docs, review, verification, and trace
   work.
3. Split work into agent-sized tasks.
4. Assign each task to a role.
5. Add dependencies.
6. For production implementation tasks, define TDD pairs or record an
   exception.
7. For experiment tasks, define the hypothesis, success criteria, storage
   location, proof, and production-boundary rule.
8. Mark `parallelizable: true` only when tasks have disjoint files or surfaces.
9. Ensure each task has proof required.

## Output

- Task files.
- Agent assignment plan.
- Parallel execution notes.
