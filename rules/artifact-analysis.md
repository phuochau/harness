# Artifact Analysis Rules

Run these checks before implementation:

1. No ready brief has unresolved clarification markers.
2. Every acceptance criterion has proof.
3. Every task traces to the brief.
4. Production implementation tasks list TDD pairs or a recorded exception.
5. Every brief requirement has a task or explicit non-goal.
6. High-risk work is not hidden in tiny or normal tasks.
7. Scope and non-goals do not contradict task instructions.
8. Parallel tasks have disjoint files, surfaces, or state.
9. Experiment tasks define a hypothesis, success criteria, storage location,
   proof, and production-boundary rule.

If any check fails, fix the artifacts before build work starts.
