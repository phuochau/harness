# Handoff Rules

Every handoff must include:

- Request or brief path.
- Task path.
- Assigned role.
- Risk lane.
- Current status.
- Required proof.
- Blockers or assumptions.
- Files or surfaces already touched.
- Experiment artifact and storage path when the task type is `experiment`.

Do not hand off vague work. If the next agent cannot tell what to do and what
proof is required, the handoff is not ready.
