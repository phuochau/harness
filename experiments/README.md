# Experiments

Use this folder for bounded proofs of concept.

Experiment code is not production code. Production code must not import from
this folder.

Each experiment should have an artifact based on `templates/experiment.md`.
In an installed project, store that artifact under `docs/delivery/experiments/`
unless the project uses another delivery-artifact layout.

After proof is collected, record whether to discard the experiment, revise the
approach, run another experiment, or promote the learning into normal
implementation tasks.
